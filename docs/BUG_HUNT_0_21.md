# Inkstone bug hunt — 29 October 2026

The requested bug-hunt playbook was applied to the native engine, Raster/Vector editors, image/project import, local storage, exports, worker callbacks, release metadata and dependencies. All 16 confirmed findings below are fixed. This is a bounded source/runtime audit, not a proof that every defect has been found.

Fourteen runtime findings were reproduced by **11 failing native tests and 3 failing Android tests before their fixes**. The two import resource findings have explicit preallocation/resource-limit regression coverage and source evidence. The added preflight compatibility test also checks that documents at the existing pixel budget remain accepted.

## Security and resource review

- Reviewed the offline app's attack surface: its launcher is intentionally exported; there is no network permission, account/session backend, database query builder, WebView or XML/SVG importer. SVG is exported with escaped labels. Document identifiers are path-validated; image export filenames remove path separators and controls; gallery output uses scoped MediaStore or the legacy permission-gated Pictures directory.
- Native/GZIP and PSD imports have input/decompression limits; PSD bounded ZIP/RLE parsing and resource checks were inspected. The native mask/metadata gaps found in that review are BH03/BH11. Native document layer IDs and groups remain validated; malicious group cycles are rejected.
- AtomicFile writes, the activity's single I/O executor and DocumentStore synchronization were inspected. A tracked-source secret-pattern scan found no token/private-key matches. This is not a forensic secret-history scan.
- All **142 registry dependency/version pairs in Cargo.lock** were queried against OSV on 29 October 2026. The only match was [RUSTSEC-2024-0436](https://rustsec.org/advisories/RUSTSEC-2024-0436.html), an **informational unmaintained** notice for `paste 1.0.15`, with no patched version. `cargo tree --target aarch64-linux-android -i paste` had no dependency path. No vulnerability advisory was returned for the locked versions in that query. This does not cover all Android OS/driver flaws or constitute a complete Maven supply-chain audit.
- Gradle is the source of the app version. The build and APK-verification scripts now derive their artifact filename from it, preventing an obsolete release filename when the app version changes. The engine crate's independent internal version is not the APK version.

## Verification and remaining boundaries

- **103** Rust tests passed; **12** normally ignored physical GPU tests also passed using Metal on this Mac. Shader validation, brush/smudge, clipping/masks, history, Fade, group appearance, multicolor and CPU/GPU fallback paths were exercised. Android Vulkan was not tested on a device.
- **132** Android framework/JNI tests passed. Android lint: **0 errors, 127 warnings**. Host JNI and both Android ABIs compiled; packaged libraries match native outputs; fourteen JNI methods, 16 KB ELF alignment and v2 APK signing verified.
- Android regression tests use Robolectric/native Skia. Physical stylus latency, palm rejection, orientation behavior, thermal behavior and animation pacing on the Xiaomi tablet remain device-test boundaries. Existing product limitations such as approximate pigment mixing and experimental Vector workflows are documented separately.
- Reproducible test names are in `crates/ink-engine/src/bug_hunt_tests.rs` and `android/app/src/test/java/art/inkstone/BugHuntTest.kt`. Findings are also available as [JSON](../artifacts/bug-hunt-results.json). Existing local group-creation tests cover three independent folders and multi-level indentation.

## Executive summary

1. **16 confirmed issues across 9 production modules**, all fixed; no confirmed finding is left deferred in this pass.
2. Severity: **Critical 3, High 10, Medium 3, Low 0**. Priorities reflect possible crashes/data loss, silent changes, and misleading preview/history behavior.
3. Fix priority: native import/paste/merge storage safety first (`lib.rs`, `selection.rs`), complete layer movement and bounded transforms next (`groups.rs`, `exterior.rs`, `transform.rs`), then UI callback lifetimes, group preview composition and brush identity (`EditorView.kt`, `RasterTransform.kt`, `RecentBrushes.kt`). Vector metadata limits are enforced in `VectorDocument.kt`.
4. Patterns observed: new exterior storage was omitted by older whole-layer operations; several mutations validated capacity after allocation or not at all; delayed UI results needed the initiating panel revision; persisted display names were being used as identity.
5. Coverage: Rust unit/shader/GPU tests and Android JUnit/Robolectric/JNI tests are configured and passing. CI publication and physical Android-device verification are distinct from these local results.
