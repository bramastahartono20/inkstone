# Bundled encoder

`jcodec-0.2.5.jar` is the pinned JCodec core release from Maven Central:

https://repo.maven.apache.org/maven2/org/jcodec/jcodec/0.2.5/jcodec-0.2.5.jar

SHA-256: `890329dad124e8b739c1d6602a59a53c8a474daddff265c2561e21c498496c81`

SHA-1 matches the publisher's Maven checksum: `0b1968a3dbf46aa5ac9630ce9e3cbf67c4940d08`.

It provides the H.264/MP4 software export fallback when Android's hardware encoder is unavailable. Its BSD license is included in the APK at `assets/licenses/jcodec-BSD.txt`. Project: https://github.com/jcodec/jcodec
